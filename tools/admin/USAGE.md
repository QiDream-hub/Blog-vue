# 博客发布工具使用说明

## 优化后的工作流程

### 核心改进

1. **文件上传即注册**：上传文件时自动生成指针并注册到 lmjweb
2. **统一打包下载**：注册完成后自动打包为 ZIP，包含已按指针命名的文件
3. **简化部署**：用户只需将 ZIP 解压到服务器对应目录即可

---

## 图片注册流程

### 步骤

1. **打开图片管理页面**
   - 点击「图片管理」菜单
   - 点击「+ 注册图片」按钮

2. **选择并上传文件**
   - 选择要上传的图片文件
   - 点击「生成指针」按钮
   - 系统会自动：
     - 在 lmjweb 中创建图片对象
     - 返回一个唯一指针（如 `01abc123...`）

3. **确认注册**
   - 点击「确认注册」按钮
   - 更新元数据中的文件名信息

4. **打包下载**
   - 系统弹出打包下载提示
   - 确认文件已重命名为指针格式
   - 点击「📦 打包下载」按钮
   - 下载包含以下内容的 ZIP 包：
     - `images/{指针}` - 已按指针命名的图片文件
     - `README.md` - 使用说明和文件清单

5. **部署到服务器**
   ```bash
   # 解压 ZIP 包
   unzip blog-images-xxxxxx.zip

   # 将 images 目录复制到 Nginx 图片目录
   cp -r images/* /path/to/nginx/image/root/
   ```

## 文章注册流程

### 步骤

1. **打开文章管理页面**
   - 点击「文章管理」菜单
   - 点击「+ 新建文章」按钮

2. **填写文章信息**
   - 输入文章标题
   - 选择文章文件（.md 或 .markdown 格式）
   - 添加标签（可选）
   - 选择封面图片（可选）

3. **生成指针**
   - 点击「生成指针」按钮
   - 系统会自动：
     - 在 lmjweb 中创建文章对象
     - 创建标签集合
     - 设置标题等元数据
     - 返回唯一指针

4. **确认注册**
   - 点击「确认注册」按钮
   - 系统会关联标签、封面等元数据

5. **打包下载**
   - 系统弹出打包下载提示
   - 确认文件信息
   - 点击「📦 打包下载」按钮
   - 下载包含以下内容的 ZIP 包：
     - `articles/{指针}` - 已按指针命名的文章文件
     - `README.md` - 使用说明和文件信息

6. **部署到服务器**
   ```bash
   # 解压 ZIP 包
   unzip article-01abc123....zip

   # 将 articles 目录复制到 Nginx 文章目录
   cp -r articles/* /path/to/nginx/article/root/
   ```

## 技术说明

### 指针命名规则

- **对象指针**：`01` 开头的 34 位十六进制字符串
- **集合指针**：`02` 开头的 34 位十六进制字符串
- 示例：`01abc123def456789012345678901234`

### 文件命名

- 上传的文件在 ZIP 包中会被重命名为指针格式（无扩展名）
- 例如：`my-article.md` → `01abc123def456789012345678901234`

### 元数据注册

注册时会在 lmjweb 中创建以下数据结构：

**图片对象**：
```json
{
  "ptr": "01abc...",
  "members": [
    {"name": "filename", "value": "original-name.jpg", "type": "raw"}
  ]
}
```

**文章对象**：
```json
{
  "ptr": "01def...",
  "members": [
    {"name": "title", "value": "文章标题", "type": "raw"},
    {"name": "tags", "value": "02ghi...", "type": "ref"}
  ]
}
```

## 常见问题

### Q: 为什么不能直接指定指针？

A: lmjweb 的指针由服务器自动生成，确保唯一性。客户端先注册获取指针，然后将文件命名为该指针。

### Q: 如果上传失败怎么办？

A: 失败后元数据可能已创建，但文件未打包。可以在图片/文章列表中删除该记录后重新上传。

### Q: 可以批量上传吗？

A: 当前版本支持单个文件上传。每次上传后会弹出打包提示，可以单独下载每个文件。

### Q: 文件需要手动重命名吗？

A: 不需要。ZIP 包中的文件已经按指针命名好，直接解压到服务器即可。
